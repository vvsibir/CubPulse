## 🔴 Критические (вероятный отказ модерации)

- [ ] **1.22 — в корне архива нет `index.html`**
  В проекте и в собранной `Release/` только `gm-1.html` и `levels.html`. Платформа грузит именно `index.html`.
  Решение: в сборке Release добавить `index.html` (дубликат/редирект на `gm-1.html`); в репо можно оставить `gm-1.html` как основной entry.

- [ ] **2.14 — не реализовано автоопределение языка через SDK i18n**
  Тексты захардкожены на русском (`gm-1.html`: «Тапни, чтобы начать», «Следующий», «Выбор уровня»; `levels.html`: «Играть →»),
  `ysdk.environment.i18n.lang` нигде не читается. Требование действует для ВСЕХ игр, даже с одним языком.
  Достаточно минимума: считать `lang` при инициализации SDK и использовать его.

## 🟠 Средние (возможное замечание)

- [ ] **2.9 — длительность контента на границе 10 минут**
  Сумма длин уровней 1–20 = 245 200 px при скорости 480 px/с ≈ **8,5 мин чистого бега** (без смертей/загрузок).
  С ретраями набегает больше, но риск есть. Зафиксировать мотивацию перепрохождения в комментарии разработчика в черновике.

- [ ] **1.6.2.1 — десктоп: активное поле не растягивается до края экрана**
  `resize()` в `game.js` всегда letterbox'ит канвас 16:9 (чёрные полосы). На широких/высоких окнах поле касается края только по одной оси.

- [ ] **1.20.3 — управление только через Pointer Events (iOS 9–12)**
  Мобильная механика на `pointerdown/pointerup` без fallback на touch (Safari < 13 не поддерживает Pointer Events).
  Формально iOS 9.0+ декларирована. Современный WebView Яндекс.Игр новее — на практике скорее пройдёт.

- [ ] **1.10.2 — `levels.html` использует системную прокрутку**
  20 карточек на маленьких экранах дают браузерный скроллбар/свайп. Допустима только собственная прокрутка средствами игры.

## 🟡 Низкие / на усмотрение (не блокируют)

  Лучше вызвать, когда появился экран «Тапни, чтобы начать».

- [ ] **1.19.4 — не подписаны `ysdk.on('game_api_pause'/'game_api_resume')`.** Формально ок (не используются), пауза платформы сейчас только через `visibilitychange`.

- [ ] **1.8 — иконка звука в канвасе ~70px (координаты 1280×720)** — при масштабировании вниз тач-зона мелкая. Можно увеличить.

- [ ] **2.2 — управление описано только в черновике** — убедиться, что поле «Как играть» заполнено (один тап = один прыжок, R — рестарт, M — звук).
