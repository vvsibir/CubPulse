# tools/ — скрипты разработки

Инструментарий проекта `gm-jump`: тесты движка, генератор уровней 4-20 с валидатором
и вспомогательные утилиты. Все пути внутри скриптов относительные (`__dirname`),
поэтому папку можно переносить вместе с репозиторием.

## Тесты (запуск: `node tools/<файл>`)

| Файл | Что проверяет |
| --- | --- |
| `sound_test.js` | Sound-модуль: unlock/startMusic/musicCut, SFX, мьют, секвенсор, все музыкальные темы и темпы, реестр THEMES.default |
| `game_input_test.js` | Интеграция: Pointer Events (один тап = один прыжок), состояние ready (музыка с первого тапа), выбор `?level=N`, меню победы/поражения, пер-уровневые темы, отрисовка, все 20 скриптов в gm-1.html |
| `levels_select_test.js` | Экран выбора: проба level-N.js по цепочке, 20 карточек, палитры, имена тем |

Прогон всех тестов:

```
node tools/sound_test.js && node tools/game_input_test.js && node tools/levels_select_test.js
```

## Генератор и проверка уровней

- `gen_levels.js` — детерминированный генератор уровней 4-20 (seed `id*7919+13`),
  с валидатором достижимости (зазоры платформ, кластеры шипов ≤ 4, вершины башен).
  **Внимание:** при запуске перезаписывает `level-4.js … level-20.js` в корне проекта.
  Проверено: текущая версия воспроизводит закоммиченные уровни байт-в-байт.
- `levels_check.js` — быстрый прогон логики `levels.html` (проба скриптов + карточки)
  в Node с моком DOM.

## Утилиты

- `serve.js` — локальный статический сервер для ручной проверки в браузере:
  `node tools/serve.js` → http://localhost:8097 (главная — `gm-1.html`, выбор — `levels.html`).
